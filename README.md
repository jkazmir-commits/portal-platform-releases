# Portal Platform – DEV releases

This public repository distributes versioned, allowlisted WordPress plugin ZIP packages for **JP Control DEV** (`https://jpcontrol.cz/dev`). The canonical source repository remains private.

The latest release is described in [`latest.json`](latest.json) once a package is published. PHP files included in public ZIP packages are accessible to everyone; do not publish secrets.

Only approved DEV releases are distributed. Neither this repository nor its workflows deploy to UAT or production.
